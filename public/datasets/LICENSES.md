## Regenerating

```text
python scripts/build-datasets.py --fetch   # download publisher files into the cache, build
python scripts/build-datasets.py --check   # rebuild into a temp dir and byte-compare
```

The download cache lives in `.agents/dataset-cache` (not committed).
